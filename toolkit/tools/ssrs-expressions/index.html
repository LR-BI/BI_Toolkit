SSRS Expression Checker

Paste SSRS expressions (or drop a whole .rdl) to catch the VB.NET mistakes that cause #Error, blank cells and deploy failures, with a fix for each and a tidy, indented version.

How to use
  1. Paste one expression, or several: each line that starts with = begins a new one. Checks run as you type.
  2. Or drop an .rdl file: every expression in the report is checked, with its location (e.g. LearnerTable › txtName) and the report's own fields, datasets and parameters used to spot typos.
  3. For pasted expressions, optionally fill in Report context (field names, datasets, multi-value parameters, and whether it's in the body or page header/footer) so those checks can run too.
  4. Each problem is highlighted in the expression and comes with a suggested fix. Tidy shows nested IIf / Switch expressions indented so you can read them.

Try Load sample first. This is a pattern checker for common mistakes; it doesn't run the expression.
