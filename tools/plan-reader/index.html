Query Plan Reader

Drop in an execution plan from SSMS to see where the time goes: costly steps, scans, key lookups, bad estimates, row fan-out, spills, per-row functions and missing indexes. Nothing leaves your browser.

How to use
  1. In SSMS press Ctrl+M (Include Actual Execution Plan) and run the query. Actual plans are far more useful than estimated ones because they have real row counts.
  2. In the Execution plan tab, right-click the plan > Save Execution Plan As…, then drop the .sqlplan file below. Or choose Show Execution Plan XML… and paste it.
  3. Work down What to look at from the top; the biggest problems come first. Click one to jump to that step in the tree.
  4. In the Operator tree, click any row for its details. Red actual rows mean the estimate was badly wrong there.
  5. Fix one thing, run again with Ctrl+M, and compare.

You need SHOWPLAN permission on the database, not server rights. Over a linked server, only a Remote step shows; the other server's work isn't in the plan. Click Try a sample plan to see an example.
