Schema Map

An ERD for a database that doesn't have one. Run one query, paste the results, then browse tables, see how they link and get JOIN SQL between any two. Nothing leaves your browser.

How to use
  1. Enter the linked server and database name. Copy the query under 1 and run it in SSMS. Optionally run the row-count query too.
  2. Click the results grid, press Ctrl+A then Ctrl+C, paste under 2 and click Load. It's saved in this browser for next time.
  3. Pick a table on the left. Search finds tables and columns, so typing a column name shows every table that has it.
  4. The diagram shows what the table links to (left) and what links to it (right). Click a box to move to that table. Dashed lines are guesses from column names.
  5. Under Join path, pick two tables to get the route between them and ready-made JOIN SQL. Check any guessed join against the data.

    How links are guessed
    
    Many vendor databases declare no foreign keys, so the tool also guesses. A column links to another table when:
    
    
    1. Its name matches that table's single-column primary key, e.g. Enrolments.StudentID to Students.StudentID. Generic key names like ID or Code don't count on their own.
    
       2. Or the target key is generic (ID) and the column is the table name plus ID, e.g. CourseID or Course_ID to Courses.ID.
    
    
    Tables with no primary key use a column called ID or <Table>ID as their key. Guessed links are dashed and marked "guess"; matching data types make a guess stronger. Always check a guessed join against the data.
