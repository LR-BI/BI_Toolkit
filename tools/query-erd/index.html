Query ERD

Paste a query and see how its tables join: a diagram of every table and alias, the join type and the columns each join uses, plus warnings for accidental cross joins, disconnected tables, LEFT JOINs undone by WHERE, and (with your Schema Map loaded) joins that can multiply rows.

How to use
  1. Paste a query. The diagram updates as you type.
  2. Wide diagrams shrink to fit the page; untick Fit to width to see them full size and drag to move around.
  3. Each box is a table (or CTE, derived table or APPLY) with its alias, the join columns in bold and the other columns the query uses. Lines show joins: solid for INNER, dashed for LEFT/RIGHT/FULL, dotted for joins written in WHERE, orange for APPLY.
  4. Queries with CTEs or subqueries have several parts: pick one under Part of query. Click a CTE box to jump to it.
  5. Download SVG / PDF / PNG saves the diagram you can see (the part of the query picked in the list). Exports always use light colours so they print well.
  6. Trace a column: click any output column to follow it back through CTEs and subqueries to the table it really comes from (the path lights up in the diagram). Click a column inside a box to see which outputs use it.
  7. What to look at lists problems; the Joins table lists every join in order with its full ON condition.
  8. If you've loaded a database in the Schema Map tool, its primary keys are used here to flag joins that don't use the whole key and so can return several rows per row.
  9. Copy Mermaid gives you the diagram as text for docs or GitHub.
