SQL Notes Block

Adds the standard notes block to the top of a query: title, a dated change log (LR - … | dd/mm/yy) and open notes. It suggests lines from the SQL itself, and if the query already has a block it adds to that block's history instead of starting again.

How to use
  1. Not sure what it does? Try Example: new query or Example: update a block (made-up queries, no real data).
  2. Paste the query on the left (or open it here from the SQL Checker or a project's SQL tab).
  3. Give it a title (the report or dataset name). If the query already has a block, the title, history and notes are read from it.
  4. Write what changed in New entry, or tick suggested lines. Suggestions are drafts worked out from the SQL (joins, grouping, filters, formats, parameters); edit them so they say what matters.
  5. Tick or type any notes: reminders and open questions, e.g. "Remove DECLARE when used in SSRS dataset".
  6. Copy the result, download it, or Save back to the project it came from. Initials, date format, width and indent are remembered.
