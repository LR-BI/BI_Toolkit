Random Password Generator

Easy-to-read passwords in the form Colour + Animal + number + symbol, e.g. TealWombat482!.

How to use
  1. A password is ready when the page opens. Click New password for another, and Copy to copy it.
  2. The symbol at the end comes from the Safe set by default. Use Full UK set for every keyboard symbol, edit the list by hand, or untick Add a symbol.
  3. Need several? Enter a number under Batch, click Generate, then Copy all. They paste into Excel one per row.
  4. These are meant for first logins that must be changed, not for long-term use.

How it works

Picks one colour (25 options), one animal (48 options), a number from 1 to 1000 and, if on, one symbol from the list, using the browser's secure random generator (crypto.getRandomValues). Nothing is sent anywhere.

The safe set skips keys that often break things or confuse users: £ ¬ (not plain ASCII), quotes, backslash, backtick, | < >. The full set is every symbol on a UK keyboard.

Without a symbol that's about 1.2 million combinations; the safe set multiplies it by 15. Fine for a first-login password the user must change; too weak for anything long-lived.
