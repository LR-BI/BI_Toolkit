Safe Change Script

Builds a script for changing live data safely: preview the rows, back them up to a BAK_ table, make the change inside a transaction, check the row count, and log the run. It's a dry run until you set @Commit = 1. You also get an undo script.

How to use
  1. Pick UPDATE, DELETE or INSERT, the table, and the key columns that identify a row (e.g. PERSON_CODE, ROLE_ID). The target table is always aliased t.
  2. Say which rows (WHERE, plus any joins) and what changes. For INSERT, write a SELECT that returns the new rows.
  3. Run the script's preview first (select it in SSMS and press F5 on just that part), count the rows, and put that number in Expected rows.
  4. Run the whole script: it's a dry run. It does everything, checks the count, then rolls back and prints what would have happened.
  5. Happy? Change @Commit to 1 and run again. The backup table and the Undo script let you put it back.
  6. First time only: run Log table setup once to create the log table.
