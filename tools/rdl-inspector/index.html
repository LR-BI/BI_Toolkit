SSRS Report Inspector

Open an .rdl report to see its datasets, SQL, parameters and every expression in one place, with checks for the usual problems: unknown or unused fields, self-referencing LookupSet, blank pages from oversized bodies, and more.

How to use
  1. Drop an .rdl file below (from your Visual Studio / Report Builder project, or downloaded from the report server). You can also paste the XML.
  2. Start with What to look at; problems that break or slow the report come first. Click one to jump to the related section.
  3. Page layout draws the page, margins and body to scale, so you can see why an export spills onto extra pages.
  4. Each dataset shows its SQL, query parameters and fields; unused fields are struck through. Check SQL opens that query in the SQL Checker in a new tab.
  5. Expressions lists every expression with where it lives (e.g. Tablix1 › Textbox12). Use the filter to find all uses of a field or parameter.
