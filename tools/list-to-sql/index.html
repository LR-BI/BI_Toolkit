List to SQL

Paste a column of values from Excel, an email or a query result and get it back as an IN list, a VALUES table or a temp table, ready to paste into SSMS.

How to use
  1. Paste your values on the left: one per line, or separated by commas or tabs. A header row can be skipped.
  2. Pick the output: IN list, VALUES table, Temp table, CTE or a plain comma list. Type a column name to get a full WHERE line.
  3. Blanks and duplicates are removed and spaces trimmed by default. Numbers are left unquoted unless you tick Always quote. Single quotes inside values are escaped for you.
  4. For long lists, Chunk size splits the output into batches (1,000 rows is the most a single INSERT … VALUES allows).
  5. Click Copy and paste into SSMS.
