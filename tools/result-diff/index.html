Result Set Diff

Paste the results of a query before and after a change and see exactly which rows were added, removed or changed, and in which columns.

How to use
  1. Run the old query in SSMS, right-click the results grid > Copy with Headers, and paste into Before. Do the same with the new query into After. CSV from Excel works too.
  2. Tick the key column(s) that identify a row, e.g. PERSON_CODE, or PERSON_CODE + UIO_ID. The tool suggests a column that's unique in both.
  3. Read the summary, then use the tabs to see Changed rows (old value struck through, new value next to it), Added rows and Removed rows. "Columns that changed" shows which columns are behind the differences.
  4. With no key ticked, whole rows are compared, so you only get added and removed.
  5. Copy keys gives you the keys of the rows on the current tab, to paste into List to SQL or a WHERE clause.
