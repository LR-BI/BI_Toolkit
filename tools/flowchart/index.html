Flowchart Builder

Draw process maps and flowcharts with swimlanes, then export them as SVG, PDF or PNG. Diagrams are kept in this browser and can be saved as files to share.

How to use
  1. Add shapes: drag one from the left onto the page, or click it to drop it in the middle. Double-click empty space to add a process step there.
  2. Type: double-click a shape or arrow to edit its text. Enter finishes, Shift+Enter adds a new line, Esc cancels.
  3. Connect: hover a shape and drag from one of its dots onto another shape. Drop on empty space to create and connect a new step in one go. Or select a shape and click a + to add the next step in that direction.
  4. Move around: drag empty space to pan, Ctrl + mouse wheel to zoom, Fit to see everything. Shift+drag on empty space selects several shapes; Shift+click adds to the selection.
  5. Swimlanes: click Add lane (with nothing selected). Double-click a lane's name to rename it; drag its bottom edge to resize.
  6. From text builds a whole chart from a list of steps (see the help inside). Tidy lays out the current chart neatly.
  7. Shortcuts: Delete remove, Ctrl+Z/Y undo/redo, Ctrl+C/V/D copy/paste/duplicate, arrow keys nudge, Ctrl+A select all.
  8. Your diagrams save automatically in this browser. Use Save file to keep a copy or send it to someone; they open it with Open file.

Build from text

One step per line. Indent the branches under a question. This replaces the current diagram (Undo brings it back).

How to write it 
(Start)                      brackets = start/end
Check fees paid?             ending with ? = decision
  Yes: Enrol learner         indented lines are branches; "Yes:" labels the arrow
  No: Send reminder -> Check fees paid?    -> jumps to a step by name
[[Run enrolment workflow]]   double square brackets = sub-process
/Learner details/            slashes = input/output
{Enrolment form}             curly brackets = document
((A))                        double round brackets = connector circle
## Admissions                ## starts a swimlane; following steps go in it
// note                      lines starting // are ignored
