EBS Validator Fixer

Rewrites what EBS Central's query validator rejects, so a query can go into a configurable screen: OUTER APPLY / CROSS APPLY and STRING_AGG. The rewritten query returns the same columns, with the same names.

How to use
  1. Paste the query on the left, or use Fix for EBS in the SQL Checker or a project's SQL tab.
  2. Each APPLY is listed with a method:
    • Scalar subqueries (default): each column becomes (SELECT TOP 1 col FROM … WHERE …). Simple and closest to the original; a CROSS APPLY also gets an EXISTS so rows without a match still drop out.
    • Join: the APPLY becomes a LEFT/INNER JOIN to a derived table, using ROW_NUMBER() to pick the TOP row. Faster when the APPLY returns several columns or the result is large.
    An APPLY that can return several rows (no TOP 1) always uses the join method.
  3. STRING_AGG(x, ', ') becomes STUFF((SELECT ', ' + x … FOR XML PATH(''), TYPE).value(…), 1, 2, ''), which works on any SQL Server version and handles & and < correctly.
  4. Read the notes under the result, then Check in SQL Checker. Before going live, run both versions and compare them in Result Set Diff.
