Workflow Viewer

Open Windows Workflow files (.xoml from WF3, .xaml from WF4) as a readable diagram, outline and property list. Add the matching .rules file and conditions show as real expressions.

How to use
  1. Drop one or more files below: the workflow (.xoml or .xaml) and, for WF3, its .rules file if there is one. You can also paste the XML.
  2. The diagram reads top to bottom. Side-by-side columns are branches (if/else, parallel, listen); dashed boxes group what's inside a sequence, loop or state. Custom (non-Microsoft) activities have a purple left edge; disabled ones are faded.
  3. Click anything in the diagram or the outline to see all its properties in Details, including bound values and conditions.
  4. Big workflows shrink to fit the page; untick Fit to width to see them full size and drag the diagram to move around.
  5. Use Find to highlight activities by name, type or any property value (e.g. a field name or rule name). Press Enter to step through matches.
  6. Below the diagram: activity types used, methods and rules referenced (missing rules flagged), and Copy outline for documentation.

Try Sample WF3 or Sample WF4 first. Files never leave your browser.
