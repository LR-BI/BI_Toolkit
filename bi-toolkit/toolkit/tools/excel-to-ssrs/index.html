Excel to SSRS Width Converter

Converts an Excel column width (in characters) to cm, inches and pixels for SSRS / Report Builder / Visual Studio, based on the workbook's default font.

How to use
  1. Set Workbook default font to your Excel template's default font (Home > Cell Styles > right-click Normal > Modify). Usually Calibri 11 or Aptos 11.
  2. In Excel, right-click a column > Column Width, and type that number into Excel column width.
  3. Copy the cm figure into the Width property of the matching SSRS column or textbox.
  4. For a whole template, paste all the widths into Batch convert and use Copy cm list.
  5. Row heights work the same way in Row height.
  6. If results are a pixel out, use Calibrate with the width and pixels Excel shows when you drag a column border.

Why the exported width shows a different number. Excel measures a column in characters of the workbook's default font. Workbooks exported from SSRS always have Calibri 11 as their default font, whatever font the cells use. So a column that shows as - in your template (-) will show as - in the export. Both are -px wide, so the column is the same physical size; only the number Excel displays changes.

Which to use: to make the export look like the template, use the cm figure above (the usual choice). If the exported file must show the same width number, set the font to Calibri 11 instead. The column will then look narrower than in the template if the template's default font is different.

Row height

Excel row heights are in points, so the default font doesn't change the conversion, and the template and the SSRS export show the same number. Excel snaps heights to whole pixels, so they go up in steps of 0.75pt at 96 DPI.

Fitting text in SSRS rows. In SSRS, a row's height is its textboxes' height, and each textbox has 2pt of padding top and bottom by default. As a rough guide, one line of text needs about 1.2 × the font size plus 4pt (Arial 12 is roughly 18.5pt, or 0.65cm). If CanGrow is on, rows grow taller to fit wrapped text, and the export follows.

Calibrate against Excel

If results look a pixel or two out: in Excel, drag a column border. The tooltip shows Width: 12.00 (89 pixels). Enter both numbers and the tool will work out the character width and use it as the override.

How it works

Excel stores column widths as a number of characters of the default font's widest digit (the "maximum digit width", or MDW), plus padding. The conversion is:

padding = 2 × ceil(MDW / 4) + 1
pixels = round(width × MDW) + padding (for widths of 1 or more)
pixels = round(width × (MDW + padding)) (for widths under 1)
cm = pixels ÷ DPI × 2.54

MDW is measured live in your browser by rendering the digits 0 to 9 in the chosen font and size. The font has to be installed on this machine. If it isn't, the browser falls back to another font and you'll see a warning. Browser text rendering can differ from Excel's by a pixel, so use the calibrate tool for exact work.

Reference: Calibri 11 at 96 DPI has an MDW of 7px, so 8.43 converts to 64px (1.69cm).
