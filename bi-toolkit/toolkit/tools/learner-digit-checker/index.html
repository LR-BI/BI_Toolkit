Learner Digit Checker

Check a list of ULNs, National Insurance numbers, postcodes and UKPRNs against the ILR rules: format, check digit and the special "unknown" values, with a cleaned-up version where it can be fixed.

How to use
  1. Paste values, one per line. A column copied from SSMS or Excel works; if you paste several columns, pick which one to check.
  2. Leave Type on Auto to work out each value's type, or pick one to check everything as that type (useful when a bad value doesn't look like anything).
  3. Results are valid, fixable (right value, wrong format, e.g. lower case or missing space; the fixed version is shown), invalid, or special (ILR placeholders like ZZ99 9ZZ or 9999999999).
  4. Copy problems copies the non-valid rows with reasons. Copy cleaned list copies every value in its original order, fixed where possible, ready to paste back into Excel.

These are format checks only. A postcode can be correctly formatted but not exist, and a ULN can pass its check digit but belong to someone else.

Rules used

ULN: 10 digits. Multiply the first nine digits by 10, 9, 8 … 2 and add them up; take the remainder after dividing by 11. A remainder of 0 is invalid; otherwise 10 minus the remainder must equal the 10th digit (ILR rule ULN_04). 9999999999 is the ILR placeholder for "not known".

NI number: 2 letters, 6 digits, then A, B, C or D. D, F, I, Q, U and V are never used as either prefix letter, O is never the second letter, and the prefixes BG, GB, KN, NK, NT, TN and ZZ aren't used (HMRC NIM39110).

Postcode: upper case, 1–2 letters then 1–2 digits (or a digit and a letter), a space, then a digit and two letters that aren't C, I, K, M, O or V (ILR postcode rules). ZZ99 9ZZ is the ILR value for an unknown postcode.

UKPRN: 8 digits, 10000000 to 99999999.
