Ontrack Field Helper

Type an EBS field name and get the selectors for its input, its hidden twin and its read-only display, plus ready-made jQuery snippets for Screen Designer CustomHTML controls.

How to use
  1. Enter the DataLink name (e.g. PersonDetails), the row (usually 0) and one or more field names, one per line.
  2. Selectors shows how to reach each field: the visible input (matched on the end of its name, skipping hidden inputs), the hidden .OriginalItem.Value twin, and the …_DISP span used when the field is read-only.
  3. Pick a snippet: read or set a value, wait for a field to appear, re-run after each ajax refresh, default a blank field, show/hide another field, or style grid cells. Your fields are filled in for you.
  4. Copy it into a CustomHTML control inside <script>…</script>. The helpers block at the top is only needed once per screen.
  5. Screens differ, so check the selector in F12 (Console: $('…').length should be 1) before relying on it.
