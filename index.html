How to use
  1. Pick a tool from the list on the left or the tiles below. Click a group's heading to open or close it; the page remembers. Ctrl+K jumps to search.
  2. Or drop a file on the box above: a .sqlplan opens in the plan reader, an .rdl in the SSRS Report Inspector, .xoml/.xaml/.rules in the workflow viewer, .sql in the SQL Checker. Pasting a query does the same.
  3. Each tool has its own "How to use" box like this one; open it when you need it. The theme button at the top right switches between light, dark and auto.
